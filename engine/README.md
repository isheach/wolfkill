# 空想圣杯引擎 (KsG - KusoGrail Engine) v1.1

## 这是什么

对《空想圣杯》系列五本规则书的**组件化重架构**(C 语言实现,可编译、可运行、可交互):

| 源书 | 在本引擎中的对应 |
|---|---|
| 《空想圣杯规则书》 | `ksg_core.c` 回合/行动/灵脉/魔力 / `ksg_battle.c` 战斗 / `ksg_state.c` 状态 / 词典与判定 |
| 《空想从者资源库》 | `ksg_data.c` 中从者技能/宝具条目(含 12 个异文库池) |
| 《空想御主资源库》 | `ksg_data.c` 中御主职业(魔术师/体术师/月姬/赝作)与子职业 |
| 《空想礼装资源书》 | `ksg_data.c` 中礼装(基础/辅助/限定/概念/职业)与科技造物 |
| 《空想工房建造书》 | `ksg_core.c` 工房组件(基本/辅助/限定/支援)、神殿 |

## 编译

```bash
# Windows(w64devkit / mingw-w64 / MSVC)
build.bat

# Linux / macOS
gcc -std=c11 -O2 -o ksg *.c
```

产物:`ksg.exe`(无第三方依赖;自动切换控制台为 UTF-8 代码页)。

## 运行

```
ksg.exe          # 交互控制台:主菜单 → 建卡/对战/演示
ksg.exe demo     # 自动沙盘演示(谕天之剑 Saber × 灼岩旋律 Lancer)
ksg.exe shell    # 旧版指令行(高级)
ksg.exe duel     # 直接进入对战
```

### 交互控制台(推荐)

```
╔══════════════════════════════════════════════╗
║        空想圣杯 KsG · 交互控制台              ║
║ 建卡 → 选技能/宝具 → 对战触发 → 结算胜率      ║
╚══════════════════════════════════════════════╝
   1) 从者建卡(职阶/属性/技能/宝具)
   2) 御主建卡(职业/属性/技能/礼装)
   3) 单位一览
   4) 开始对战(双方触发→结算)
   5) 自动沙盘演示
   6) 进入指令 Shell(高级)
```

**对战流程(真实结算,非录文本)**:每个战斗工序(战斗开始时/初始/主要/最终)都会停下,
询问双方"要不要发动技能/解放宝具"——列出可用能力(时机+魔耗+回转),玩家选择后
立即按效果链结算:胜率修正、即死判定、属性补正、状态赋予、魔力消耗都会真实改变
战场数字,并在战斗计算表中可见;最后按双方最终胜率掷骰决胜,战败方被俘虏。

### 建卡(带 UI)

- 从者:9 职阶(含 Ruler/Avenger)→ 初始等级 40~70 → 160 点属性交互分配(1+ / 2- 增减)
  → 六面向技能各购一个 → 11 面向宝具选 2 件 → 生成卡面
- 御主:5 主职业 → 80 点属性+回路 → 购技能 → 购礼装


## v1.4 新增细则

- **游荡状态完整实现**(规则8.1):游荡单位回合结束无法获回转补充;御主[耐久*2%]疲惫判定、
  从者[等级%]判定(成功=等级-30魔耗/失败=疲惫1);游荡中行动判定成功率至多10%;游荡中休整获得疲惫1
- **礼装每轮使用上限**:御主每轮5次、从者0次、Caster视为御主放宽;单件可复用礼装每轮1次;轮次开始重置
- **隐藏属性建卡**:天(60~70,神性)/地(50~70)/人(40~60)/星(40~60)/兽(固定70);
  等级范围由隐藏属性强制;天自动获得[神性]特性;卡面显示隐藏属性
- **召唤物系统**:EF_SUMMON 效果类型——按等级/总属性/特性生成召唤物,战斗中有空位则入仆役位;
  无魔力池的召唤物每轮次维护费(等级/2)由所有者(御主)代付,否则退场;
  战败的召唤物/人偶直接摧毁而非俘虏(词典规则)
- 效果判定语义修正:固定成功率(chance)优先于属性判定(chance_attr_base),无判定效果不再被误判失败

## v1.3 新增细则

- **结算链引擎**:一次工序内双方先提交全部能力,再按链结算:
  能力(宝具→技能→礼装)→ 类型 → 等级(EX→A→B→C→D→E→-) → 时机(常驻→指定工序→随时)
- **[蓄力]** 完整语义:宣言后进入蓄力队列,经过指定工序数后自动解放
- **[爆发]** 完整语义:额外支付一份魔耗,效果再次生效一次
- **工房/神殿建造流程**:选择组件、逐回合[建设1]、完成后组件效果在战斗中真实生效
  (魔能重炮-40%胜率 / 黑厄深阱抗性+10% / 集束光标+40% / 强能法阵+30魔力 / 医疗装机-3层异常)
- 同一能力不可重复提交;魔耗不足/回转未完成给出明确失败原因
