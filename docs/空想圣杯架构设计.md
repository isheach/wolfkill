# 《空想圣杯》五书架构重构 · 设计文档

> 对应引擎:`engine/` 下的 KsG (KusoGrail) C 语言实现,可编译运行。
> 本文档回答三个问题:五本书之间是什么关系、每一本提供的组件是什么、引擎如何一一复刻。

## 一、五书总览与关系图

```
                        ┌─────────────────────────────┐
                        │   空想圣杯规则书 (核心引擎)   │
                        │  回合/行动/灵脉/魔力/契约/    │
                        │  战斗/回转/令咒/词典/建卡     │
                        └──────┬──────────┬──────────┘
                               │ 定义“资源”的          │ 定义“场地”的
                               │ 数据结构与使用规则      │ 数据结构与使用规则
              ┌────────────────┴───┐   ┌───────────────┴───┐
              ▼                    ▼   ▼                   ▼
   ┌─────────────────┐  ┌──────────────────┐  ┌──────────────────┐
   │ 空想从者资源库   │  │ 空想御主资源库    │  │ 空想礼装资源书    │
   │ (从者的RP体系、  │  │ (御主RP/职业体系、│  │ (礼装分类与模板、 │
   │  技能/宝具大库, │  │  子职业/技能大库) │  │  科技造物)       │
   │  12个异文库池)  │  │                  │  │                  │
   └─────────────────┘  └──────────────────┘  └──────────────────┘
                    资源统一模板                        │
                    技能/宝具/礼装同构                    │ 工房组件之间
              ┌────────────────────────────────────────┴────────────┐
              ▼                                                       ▼
   ┌──────────────────┐  交互:工房组件/神殿 是“灵脉上的建筑”,进战斗
   │ 空想工房建造书   │  =“战场环境的属性”;灵脉持有者=工房宿主
   │ (组件/神殿/规模/ │
   │  稳态/建设层数)  │
   └──────────────────┘
```

**核心思路**:规则书是"引擎",三本资源书是"内容包",工房书是"地图对象"。
规则书定义了资源(技能/宝具/礼装)的**统一模板**(类型/发动时机/魔力消耗/回转/特效/效果文本),
三本资源库只是按该模板填数据;工房书定义**可建造对象**,挂在灵脉上。

## 二、规则书 = 核心引擎(组件拆分)

### 2.1 六大子系统

| 子系统 | 章节 | 关键组件 |
|---|---|---|
| 回合引擎 | 第一章 1-2 节 | 轮次(昼+夜)、时点链、准备期/本选/决战日 |
| 行动引擎 | 第一章 3 节 | 10 类行动:机动/魂食/干涉/解放/制造/建设/侦查/调查/休整/摧毁工房 + 介入/协助 |
| 灵脉引擎 | 第一章 4 节 | 魔力量/人流量/灵脉主/大中小空灵脉/工房挂载 |
| 魔力引擎 | 第一章 5 节 | 魔力池(模块化)、消耗(等级/常驻/即时)、供给(回路/灵脉/圣杯/特殊)、结算、转移 |
| 交互引擎 | 第二章 | 7 种契约(圣杯/同盟/不战/魔力/强制/奴役/决斗) |
| 战斗引擎 | 第三章 | 战斗位/战场宽度/工序机/结算链/胜率/战术/指令/撤退/俘虏/游荡 |
| 资源运转 | 第四章 | 回转(CD):工序+1、回合+3 |
| 强制指令 | 第五章 | 令咒 8 种用法 |
| 状态词典 | 附录三 | 强化 7 / 弱化 8 / 异常 11 / 特效(战场/单位/资源) |
| 建卡 | 附录一/二 | 从者 24RP、御主 12+等级 RP |

### 2.2 回合时点链(规则书 2.3.1)

```
轮次开始时 → (昼)回合开始时 → 行动提交 → 行动结算 → (昼)回合结束时
          → (夜)回合开始时 → 行动提交 → 行动结算 → (夜)回合结束时 → 轮次结束时
```
结算顺序:灵脉效果 → 工房效果 → 技能与宝具效果 → 魔力结算 → 其他效果。

### 2.3 行动结算顺序(规则书 3.12)

```
机动 → 魂食 → 干涉 → 解放 → 制造 → 建设 → 侦查 → 调查 → 休整 → 摧毁工房
```
交流中:进入交流 → 其他行为 → 袭击 → 退出干涉/进驻 → 交流结束。

### 2.4 战斗状态机(第三章)

```
战斗开始时(展露环境→决定参战→魔力结算→冲锋→展露常驻→提交能力→结算链→战术)
 → 初始工序(能力提交→结算→主要属性→随机属性)
 → 主要工序(同上)
 → 最终工序(同上→死斗宣言)
 → 战斗结束时(决胜检定→俘虏→等级魔耗→魔力结算)
```
**结算链**(5.2):效果→能力→类型→等级→时机→状态,每层有内部次序。
**胜率公式**:战斗属性(主要+随机,1点=1%)+胜率补正/惩罚 - 属性差优势 → 最终 1~100 决胜。
**战术环**:强击 > 破袭 > 试探 > 扼守 > 强击。
**指令**:冲锋/追击/掩护/死斗。
**撤退**:FP 随工序递增(初始0FP→主要1→最终2→结束时3),主力位可被替换。

## 三、三本资源书 = 内容包(统一模板)

### 3.1 资源统一模板(引擎 `ks_res_t`)

| 字段 | 规则书词条 | 引擎字段 |
|---|---|---|
| 名称+等级 | 技能/宝具名、A-E/EX/- | `name`/`rank` |
| 类型 | 技能:职阶/天赋/技艺/祝福/荣冠/兵器/魔术;宝具:对人/对军/对城/对界/结界… | `type` |
| 面向 | 建卡限制(每种至多1个) | `type`(技能与宝具类型分离) |
| 发动时机 | 常驻/行动阶段/战斗开始时/指定工序/随时 | `when` |
| 魔力消耗 | 数字或公式 | `cost` |
| 回转 | CD 数值(常驻=0) | `recast`/`cur_recast` |
| 特效 | [主力位]/[支援]/[反击]/[骑乘]/[蓄力]/[必中]/[无敌贯通]/[爆发] | `feat`(位掩码) |
| 效果文本 | 自然语言 | `text`(原文保留) |

### 3.2 从者资源库的层级

```
空想从者资源库
├── 建卡相关(24RP、栏位、加符、EX等级规则)
├── 基础资源库
│   ├── 职阶技能(对魔力/骑乘/单独行动/阵地制作/道具制作/气息遮蔽/狂化…)
│   ├── 保有技能(天赋/技艺/祝福/荣冠/兵器/魔术 六面向)
│   └── 宝具一览(决战/即死/魔剑/防御/进攻/增益/召唤/状态/补给/特殊/特攻 11面向)
├── 外典资源库   ├── 京都资源库  ├── 苍银资源库   ├── 北欧资源库
├── 深池资源库   ├── 军阵资源库  ├── 90赤幕资源  ├── 物语资源库
└── 辉拓/少女/战线/盈月资源库(各含职阶技能与宝具)
```

### 3.3 御主资源库的层级

```
空想御主资源库
├── 建卡相关(RP=12+等级LRP、工房组件栏/技能栏/礼装栏、加符、特殊EX)
├── 基础资源包
│   ├── 主职业·魔术师(子职业:人偶师/结界师/咒术师/炼金术师)
│   ├── 主职业·体术师(子职业:武术家/刽子手/剑术师/武士)
│   └── 通用技能(魔眼/后勤/战斗)
├── 通用子职业:卢恩使、魔眼使
├── 月姬扩充包:异能者(死徒/退魔师/混血)、代行者(驱魔师/修道士/圣堂骑士)
└── 赝作扩充包:执法者(军部/权贵)  ← 引入 [资金] 与 [科技造物]
```

### 3.4 礼装资源书

```
基础礼装(一次性):替身札纸/咒符/魔弹宝石/魔法箭矢/魔力水晶/契约之书
基础礼装(可复用):侦查使魔/传讯使魔/建筑使魔
辅助礼装:水银剑/宝石吊坠/红宝石手杖(均含独立魔力池)
限定礼装:白鹳骑士/月灵髓液/以太光纤/伪臣之书/连接强化型
概念武装:黑键/灰锭/圣骸布系列/守护圣典
职业礼装:巫蛊人偶/龙告令咒/职介卡/封印礼装/卢恩符文/护身结界/愉快型/魔力弹药/调律器
科技造物(不属礼装但同判定):摩托/机枪/步枪/火箭筒/手枪/弹药包
```

### 3.5 工房建造书 = 地图对象

```
工房组件:基本(信息/资源/炼金基盘,建设1)→辅助(强能/医疗/聚合,建设2)
         →限定(黑厄深阱/魔能重炮/制裁机关/增幅模块,建设3)
         →支援(传输阵式/集束光标/术控主脑,建设4)
神殿:圣所/圣殿/圣灵基盘 + 大观星台/大祭祀场/大秘仪所
规则:每工房一基本组件、规模上限、稳态(摧毁所需魔耗)、工房主唯一
```

## 四、引擎复刻对照(书 → C)

| 书内组件 | 引擎位置 | 说明 |
|---|---|---|
| 世界/灵脉/单位/资源/契约/战斗上下文 | `ksg.h` 全部结构体 | 数据即规则 |
| 时点链、行动注册与顺序 | `ksg_core.c` `ks_action_register` / `ks_action_do` | 行动表 = 策略模式,10类行动注册 |
| 判定三层修正 | `ksg_core.c` `ks_check_*` | 基础/最终成功率分离,负面判定吃抗性 |
| 魔力池/消耗/供给/结算 | `ksg_core.c` `ks_mp_*` | 从者150/-100、御主回路/-50、额外池 |
| 回转 | `ksg_core.c` `ks_recast_*` | 回合+3/工序+1 |
| 状态与词典 | `ksg_core.c` `ks_status_*` | 强化/弱化/异常,时点衰减 |
| 战斗位/宽度/工序机 | `ksg_battle.c` `ks_battle_tick` | 5相状态机(开始/初始/主要/最终/结束) |
| 结算链 | `ksg_battle.c` `ks_battle_cast_skill` | 按效果链逐行结算+回转 |
| 胜率/战术/指令 | `ksg_battle.c` `ks_battle_*` | 战术克制环、冲锋/死斗等 |
| 资源数据库 | `ksg_data.c` `ks_data_build` | 从者职阶、约50条技能/宝具 + 礼装/科技 + 工房组件 |
| 建卡模板 | `ksg_data.c` `ks_data_make_unit_sheet` | 职阶基础属性 + 分配 |
| 交互 | `ksg_sim.c` | Shell 命令 + 自动沙盘演示 |

## 五、演示(沙盘)验证链路

`ksg.exe demo` 自动跑通:

1. **建卡**:谕天之剑(Saber Lv60)契约言峰教会代行;灼岩旋律(Lancer Lv60)契约时钟塔资深;双方圣杯契约。
2. **回合**:第1轮昼,提交 干涉/制造/侦查/调查 四类行动,按行动顺序结算,干涉进入交流并触发遭遇。
3. **战斗**:战场宽度4,战术选择与克制、战斗属性(主要+随机)、宝具解放与回转、冲锋/死斗指令、最终胜率与决胜检定、战败方俘虏、等级魔耗结算。
4. **轮次结算**:魔力结算(上限抹除)、等级魔耗、灵脉供魔、状态衰减、回转补充。
